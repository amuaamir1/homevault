## Status

## Implementation

GH-73 implements fixed warranty reminder milestones at:

- 30 days before effective warranty expiry
- 7 days before effective warranty expiry

Warranty reminders remain opt-in.

Effective expiry uses the later applicable standard or extended warranty expiry.

Passed milestones are skipped. There is no warranty expiry-day fallback.

Warranty notification mutations are serialized to avoid cancellation/scheduling races.

Reminder Center shows one logical warranty reminder card with both 30-day and 7-day milestone rows.

The legacy warrantyReminderDaysBefore value remains preserved for backward compatibility but is inactive for runtime scheduling and user-facing configuration.

Warranty CSV export explicitly distinguishes:

- Legacy reminder days before (inactive)
- Active warranty reminder policy

AMC and maintenance behavior remain unchanged.

No backend, Firebase rule, schema, migration, dependency, deployment, signing, or production-data changes are included.
